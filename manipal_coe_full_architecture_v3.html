AI agent system
Multi-agent ReAct architecture — three primary agents coordinated by an orchestrator
DischargeExtractorAgent — PDF to structured data
  • Reads PDF via PDF reader tool and segments pages into chunks
  • Runs 7 sequential skills: DocumentAnalyser → Demographics → RiskScores → Vitals → FunctionalStatus → ClinicalData → CrossValidator
  • Each skill builds progressively on previous outputs (progressive enhancement)
  • CrossValidatorSkill verifies every field against source PDF with character-level citations
  • Merges all skill outputs, resolves conflicts, assigns confidence scores per field
  • Produces structured JSON with full provenance tracking for every extracted value
ReAct pattern7 skills30–45s avg
DoctorAssistantAgent — interactive clinical Q&A
  • QueryIntentAgent classifies query type: vitals / meds / diagnosis / general
  • Consent gate — prompts clinician before triggering any external medical search
  • RecordContextAgent searches extracted clinical data with relevance scoring
  • ExternalKnowledgeAgent fetches approved medical sources (only when consented)
  • SafetyGuardAgent cross-checks LLM output for hallucinations and unsafe advice
  • AnswerComposerAgent synthesises internal + external evidence with citations attached
  • ActionRouterAgent proposes clinical actions formatted as UI confirm/reject cards
  • SessionMemoryAgent maintains full conversation state across turns
8 sub-agentsSafety-first3–8s avg
ChartNoteAgent — SOAP note generation
  • Step 1 THINK: analyses clinical picture — admission reason, key events, discharge condition
  • Step 2 THINK: plans SOAP structure — determines required elements per section
  • Step 3 WRITE: Subjective — chief complaint, illness narrative, patient perspective
  • Step 4 WRITE: Objective — vitals, exam findings, abnormal labs, risk scores
  • Step 5 WRITE: Assessment — principal & secondary diagnoses with clinical reasoning
  • Step 6 WRITE: Plan — discharge medications, activity restrictions, follow-up
  • Step 7 THINK: self-quality-check, missing element detection, citation attachment
THINK+WRITESelf-refinement15–25s avg
